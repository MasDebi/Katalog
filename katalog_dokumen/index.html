Pertanyaan Umum

Apakah dokumen langsung jadi otomatis?

Data kamu akan dikirim ke admin terlebih dahulu, lalu admin merapikan dokumen sebelum dikirim kembali via WhatsApp.

Apakah bisa revisi?

Bisa. Revisi ringan seperti perbaikan nama, posisi, perusahaan, atau kalimat masih bisa dibantu.

Dokumen dikirim dalam format apa?

Dokumen dapat dikirim dalam bentuk PDF melalui WhatsApp.

Apakah data saya aman?

Data tidak disimpan di website. Data hanya dikirim ke admin melalui WhatsApp untuk diproses.
